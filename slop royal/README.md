# Slop Royale 👑

A very basic, functional, playable clone of Clash Royale — pure HTML/CSS/JS, no build step or dependencies.

## How to run

Just open `index.html` in any modern browser (double-click works), or serve the folder:

```
npx serve .
```

## How to play

- **Deploy troops**: tap/click a card (or press `1`–`4`), then tap your half of the arena. Spells can be cast anywhere.
- **Cancel selection**: `Esc` or right-click.
- **Goal**: destroy enemy towers to earn crowns. Destroying the King Tower wins instantly.
- **Timer**: 3:00 regulation (most crowns wins) → Sudden Death overtime if tied.
- **Elixir**: refills over time (max 10); Double Elixir in the last minute.
- **Sandbox**: from the menu, hit `SANDBOX` — no AI, no clock (`P`/`Space` pauses), spawn any card as any team anywhere.

## Mechanics implemented

- Bridge pathfinding across the river, unit collision/separation
- Aggro targeting (units vs towers, building-only tanks)
- Homing projectiles + splash damage
- King Tower activation (wakes when damaged or a princess tower falls)
- 4-card hand + cycling queue with next-card preview
- Enemy AI: defends pushes, counter-attacks lanes, spell value plays, elixir leak avoidance
- Crowns, double elixir, sudden death overtime, HP-drain tiebreaker
- Destroying a princess tower unlocks that enemy lane for your deployments
- King Tower destruction = instant three-crown victory
- **Saint Goblinator aura**: friendly goblins get a speed blessing; enemy goblins are converted. A goblin covered by two opposing saints at once goes immune, insane, and joins the rogue **green team**
- **Green team** attacks everyone. Green units spawn with −70% HP, −60% damage, +150% attack speed and +100% move speed so outbreaks stay containable. When a green unit kills a non-tower, the victim rises as a green version of itself
- **Slop Master**: picks up an enemy on contact (3s channel, 8s for towers — victims can still fight back but can't move), shouts "SLOP!", sprints to the river and drowns them with a splash. Towers score crowns only for blue/red killers
- **Sandbox mode**: free spawning of every card as blue/red/green, pause/resume, endless timer

## Code layout

```
index.html              page shell + HUD
css/style.css           styling
js/constants.js         arena geometry & match rules
js/cards.js             card/tower stats
js/entities.js          Unit / Tower / Projectile classes
js/ai.js                enemy AI controller
js/render.js            canvas rendering (uses unit sprites, emoji fallback)
js/main.js              game state, input, loop, HUD
scripts/generate_sprites.js  placeholder pixel-art PNG generator (no deps)
assets/sprites/         generated unit sprites (<unit>_<team>.png)
```

## Sprites

Units use placeholder pixel-art PNGs generated by a zero-dependency Node script.
Each sprite is a character map recolored per team ('B'/'b' = team colors) and
upscaled 4x with nearest-neighbor. Green-team sprites are produced by multiplying
the blue sprite's pixels with a green tint. To tweak the art, edit the maps in
the script and regenerate:

```
node scripts/generate_sprites.js
```

If a sprite file is missing or fails to load, the renderer falls back to the
original circle-and-emoji look.
